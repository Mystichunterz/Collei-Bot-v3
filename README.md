# Collei Bot

Collei Bot is a multi-purpose Discord Bot built for the discord.gg/sumeru community by Mystichunterz, built using the discord.js library and is hosted on a Raspberry Pi.

## Contributing

**Before adding or editing a command that sends user-provided text, read [ALLOWED_MENTIONS.md](ALLOWED_MENTIONS.md).** Any message whose `content` includes user input must set `allowedMentions: { parse: [] }` to prevent `@everyone`/role-mention ping injection.
